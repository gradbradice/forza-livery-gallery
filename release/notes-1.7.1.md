## English

* The gallery now asks before installing an update. When a new version is out, it says so in the status bar, and the version is downloaded and installed only after you press "Install" in its window. To have updates install on their own as in 1.7.0, choose "Install automatically" in "Settings → Gallery → Updates".
* The card's context menu now has "View in one more 3D window", to compare liveries.
* The gallery opens where it was when you closed it, maximized if it was. No window opens bigger than the screen any more: on smaller screens or with display scaling, the top of the window used to end up off the screen.
* A new setting, "Keep the storage's folders as folders on disk", in "Settings → Folders". It is off by default, and everything works as before: the liveries lie right in the storage folder, and the gallery's folders are labels.
* Stored liveries without a preview of their own now get one drawn by the gallery, like liveries in the game. It is kept with the livery in the storage.
* Fixed: with the storage in a folder of its own chosen in the settings, the 3D view opened the livery from the game with the same key or did not open at all, and the full preview was not found.
* The account's name now comes from the save itself. The livery server reads it together with the list of liveries on cars, if "Use the server to find the liveries on cars" is on in "Settings → Livery server". Until the server has sent the name, the account is named by the nickname on the account's things.
* Fixed: small errors of the 3D view on some models.
* The livery badges are on the picture again, as in 1.7.0, but now they are round icons in two groups. In "Settings → Appearance → Livery cards" the badges can be moved to the bottom of the card.
* The same badges are now in the livery window and in the "Changes since the last start" window.
* If a livery has no author, the gallery now looks for possible authors among the stored liveries too.
* In the filter menu each filter now has the same icon as on the card: on cars, my liveries, duplicates, generated, paint only, auction.
* The car's make on the card is now plain text, without a chip. Chips remain on tags, and the badges are icons now, so they are easier to tell apart.
* 3D windows are now ordinary separate windows: the gallery can cover them, Alt+Tab switches between them and the gallery, and each has a "Minimize" button. The 3 key brings the current 3D window back from minimized or from under the gallery. The earlier behaviour, 3D windows always above the gallery, is turned on with the "Over the main window" button in the 3D window itself.
* With several liveries selected, Shift+3 and the context menu's "View the selected in separate 3D windows" open each in its own window, in the gallery's order. No more than four 3D windows can be open at once.
* In a 3D window Shift+← and Shift+→ open the previous or the next livery in a new window, and the current one stays as it is. The gallery selects the livery opened, as with the plain arrows.
* A new filter: "In the storage" (when the game is shown) or "In the game" (when the storage is shown).
* Fixed: a livery put into the storage by hand had no number (#). It now gets one, like a livery from the game.
* Fixed: errors in the translations.
